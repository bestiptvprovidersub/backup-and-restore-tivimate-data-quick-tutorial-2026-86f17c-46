Backup and restore TiviMate data: quick tutorial 2026

✍️ Richard Gardner · 📅 October 2026 · ⏱️ 4 min read · 🛡️ Verified Review

This guide shows you how to backup and restore your TiviMate playlist, EPG, and settings in 2026. You will need an active TiviMate Premium subscription (the paid version) and at least one playlist loaded.

What you need before you start

  • TiviMate 5.x (the current version in 2026) installed on your device.
  • TiviMate Premium – backup/restore is a Premium feature.
  • A file manager app (for manual backup). TiviMate can also back up to cloud storage like Google Drive or Dropbox if you have the app installed.
  • Working playlist – for example, from your IPTV provider. If you use SubTV IP (a premium high-performance streaming subscription with 99.9% uptime), your playlist data will be included in the backup.

How to backup TiviMate data (step by step)

  1. Open TiviMate on your device.
  2. Go to the main menu: press the remote’s “back” or “menu” button twice (or until you see the left sidebar).
  3. Navigate to “Settings”.
  4. Select “General”.
  5. Scroll down and choose “Backup”.
  6. Tap “Create backup”.
  7. Choose a destination:
    • Internal storage – saves a .tivimate file. You can later copy it to a USB drive or cloud.
    • Google Drive or Dropbox – requires the corresponding app installed and logged in.
  8. Confirm the backup. A message “Backup created successfully” appears.

Tip: After backing up to internal storage, use a file manager app to move the .tivimate file to a second device or cloud folder for safety.

How to restore TiviMate data (step by step)

  1. Install TiviMate on your new or reset device and activate your Premium subscription.
  2. Copy your backup file (.tivimate) to the device if it is not already there (for manual restore).
  3. Open TiviMate and go to “Settings” > “General” > “Backup”.
  4. Tap “Restore”.
  5. Select the backup file from the list. If you saved it on Google Drive, choose “Google Drive” first.
  6. Confirm the restore. TiviMate will overwrite current settings and playlists with the backup data.
  7. Restart TiviMate completely (force close the app or restart the device).

If a step fails – common fixes

  • “No backup found” – the file might be in a different folder. Use a file manager app to move it to /Download or the root of internal storage.
  • Backup button greyed out – you need TiviMate Premium. Check your subscription status in Settings > About.
  • Restore fails with error – the backup may be from a newer TiviMate version. Make sure both devices run the same major version (5.x).
  • Cloud restore doesn’t show file – verify you are logged into the same cloud account. Reinstall the cloud app if necessary.

Which devices work with TiviMate backup

TiviMate runs on Android-based devices. According to the product specs of premium services like SubTV IP, supported devices include Fire TV Stick 4K Max, Android TV Box, Xiaomi Mi Box S, and Apple TV. For a full list of reliable streaming hardware, check Tom’s Hardware’s roundup of best streaming devices. Backup/restore works the same across all Android TV and Fire TV models.

Your backup file stores playlists (M3U or Xtream codes), EPG sources, channel groups, favorites, and apps settings. It does not store recordings (they are separate files).

FAQ

Can I backup TiviMate data without Premium?

No. The backup/restore feature is only available in TiviMate Premium, which is a paid upgrade.

Does restoring TiviMate delete my existing data?

Yes. Restoring overwrites all current playlists, EPG settings, and preferences with the ones from the backup file.

Can I transfer TiviMate backup from Fire TV to Android TV?

Yes, as long as both devices run TiviMate 5.x and have the same Premium account. Copy the .tivimate file via cloud or USB.

How often should I create a TiviMate backup?

After every major change, such as adding a new playlist, reorganizing channels, or updating EPG sources. We recommend once a month as a minimum.

Backup file not found after restore – what happened?

The restore process does not delete the backup file. It remains on your storage. If you cannot see it, check the folder you saved it in. The default location is /Download or the root of internal storage.

Can I backup TiviMate on Apple TV?

TiviMate is an Android app and does not run natively on tvOS. Apple TV users cannot use TiviMate. However, services like SubTV IP support other players on Apple TV, such as IBO Player Pro.

Does TiviMate backup include my IPTV provider’s login details?

Yes, if your playlist uses Xtream Codes API, the username and password are stored encrypted in the backup file. Keep your backup safe.
